计算说明

  • 合成期货价格 = Call - Put + K（认购-认沽平价，买入认购+卖出认沽 = 合成多头期货）
  • 贴水 = 合成期货价格 - 现货价格（负值 = 贴水，正值 = 升水）
  • 贴水率 = 贴水 / 现货价格 × 100%
  • 年化贴水率 = 贴水率 × 365 / 剩余天数
  • 每个行权价独立计算合成期货（该行权价的 Call - Put + K），行权价配对按同月份同行权价自动匹配
  • 绿色高亮行 = 平值合约（行权价最接近现货价）
  • 500ETF 行权价带"A"后缀表示经分红调整后的合约
  • 500ETF 2027年3月合约新浪源有数据，Wind 源未返回（数据源差异）
  • 贴水为负通常反映：市场看空预期 + 分红预期 + 做空需求旺盛
  • 500ETF 年化贴水显著高于其他品种，隐含较高的分红预期或对冲需求
